# JUMPOBBY-2
วิธีเล่น ผู้เล่นที่ 1 กด WASD ในการเดินและกระโดด w คือปุ่มกระโดด
      ผู้เล่นที่ 2 กด ลูกศร ในการควบคุมการเดิน และ กดลูกศรขึ้นเพื่อกระโดด
      ในแต่ละด่านจะแตกต่างกันออกไปจะมีอุปสรรคต่างๆในการกระโดดหลบและเก็บแต้มเพื่อได้คะแนนและเพิ่มเลือดนิดหน่อย
      ใครอยู่รอดคนท้ายและได้แต้มเยอะสุดจะได้ชนะเกมนี้นับทั้งแต้มและการยืนอยู่รอด
      ผู้เล่นที่ตายสามารถกดปุ่มในการปล่อย Object มาก่อกวนให้ผู้เล่นอีกคนตาย ผู้เล่นที่ 1 จะกด spacebar ผู้เล่นที่สองจะกดปุ่ม Shift เพื่อปล่อย object มาก่อกวนและมีคูลดาวน์อยู่ 30 วินาที
